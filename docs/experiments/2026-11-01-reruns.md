## 2. Old c3852df code

The pre-integration root-`model.py` LinA/RAT (296×9 h37, level 1, 22k steps,
same FineWeb bins) reaches **val 1.3703** in 2.88 h. Current RAT 11M is
**1.2684/1.2845**. The old code is ~0.09 nats worse; the integration and the
chunked-scan/gamma work **improved** RAT. No regression found.

## 3. HyperFormer head/LR test

The h37 test **OOM'd** at block 1024: 37 heads × full 1024² attention needs more
than a 14.5 GB T4. The old 8-head/3e-4 hyper result stands at **1.3381**, worse
than both 11M arms. A fair head-matched hyper test needs smaller batch/block or
memory-efficient attention; it is not a conclusion about the architecture yet.

L2 reached 18k steps (val 1.3813) before cancellation; level 2 is not promising.

## Verdict

- Integration did **not** break RAT.
- The 11M Real exception was **data-order luck**; corrected RAT is ahead.
- HyperFormer still has a real config/training problem; h37 needs a memory fix.
