# RealGPT 48M lower-LR bracket (2026-11-07)

The 48M RealGPT anomaly was an **optimizer** problem, not an architecture result.
Two lower-LR arms were run on the same FineWeb data / block / batch / seed as the
earlier pair; one completed, one was cut by the 12 h Kaggle cap.

## Results

| arm | lr | steps | train | val | status |
|---|---:|---:|---:|---:|---|
| RealGPT 48M, old baseline | 3e-4 | 22k | 1.5262 | 1.5523 | completed earlier |
| RealGPT 48M, old probe | 5e-4 | 35k | 1.5382 | 1.5476 | completed earlier |
| RealGPT 48M, **new best** | **1e-4** | **36k** | **1.2388** | **1.2485** | completed, 9.57 h |
| RealGPT 48M, low-mid | 2e-4 | 35.5k | 1.3920 | 1.3960 | Kaggle cap; last eval |

Same 90.1M chars, block 1024, batch 4, seed 1337, data-order fix, current source
with the #23 stable L1 scan. The 2e-4 arm was still running at the 12 h cap; its
last eval is at 35.5k.

## Reading

- **1e-4 is a large win for the Real48 model itself**: 1.2485 vs 1.5523 at
  3e-4/22k. It happens to beat the reported RAT44 (1.2911) and best RAT33
  (1.2540) numbers, but those RAT rows still use 3e-4. This is **not** a fair
  LR-tuned architecture comparison; a matched RAT44 1e-4 run is in flight.
- The response is **non-monotonic**: 1e-4 works, 2e-4 is much worse (1.3960), and
  3e-4/5e-4 are back around 1.55. This needs a proper bracket (5e-5, 1.5e-4) and a
  second seed before calling 1e-4 the optimum; one run is not a scaling law.
- RAT's genuine result is still **parameter efficiency**: 33M/44M RAT is close to
  the 48M Real at 2x fewer/lower params, and 11M RAT is strong at 8 chars/param.
  That claim also needs a matched-LR RAT rerun.
- The canceled 2e-4 arm is not a failed run; it was cut by the session cap with a
  valid last eval and checkpoint.

## Fairness rule (do not forget)

Real48 beating RAT44 at the same parameter count is still **weird** and currently
unfair: Real has an LR search, RAT does not. If Real gets hyperparameter
optimization, RAT gets the same budget and the same kind of search before any
architecture claim. The 1.2485 Real result is a tuned-vs-untuned comparison until
the matched RAT 1e-4 arm lands; do not publish it as "Real beats RAT".
